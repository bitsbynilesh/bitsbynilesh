### 🚍 GatiGo

A real-time transit and vehicle tracking Progressive Web Application engineered for live geospatial telemetry, route coordination, and interactive transit visualization.

* **Architecture & Implemented Features**:
  * Cross-platform Progressive Web App built with **Next.js**, **React 19**, and **TypeScript**.
  * Interactive map tracking powered by **Leaflet** & **React-Leaflet** for real-time location plotting.
  * Bidirectional WebSocket telemetry powered by **Socket.io** for low-latency live coordinate updates.
  * Relational backend built with **Node.js**, **Express**, and **PostgreSQL** (`pg`) for route, schedule, and trip tracking.
  * Secure authentication flow with JWT tokens, bcrypt password hashing, and dynamic QR-code boarding verification.

`Next.js` · `TypeScript` · `Socket.io` · `Leaflet` · `PostgreSQL` · `Express` · `PWA`

<br>

### 🧠 [OnePrompt AI](https://github.com/bitsbynilesh/OnePrompt-AI)

A modular AI orchestration platform engineered for deterministic evaluation, prompt synthesis, and multi-candidate model execution.

* **Implemented Orchestration Features**:
  * Multi-candidate execution pipeline querying and dispatching multiple candidate model configurations concurrently.
  * Strict evaluation context isolation, separating raw user queries from candidate execution prompts to eliminate context leakage during scoring.
  * Automated response synthesizer testing to systematically benchmark candidate outputs.
  * Deterministic test suite verifying invariant checks, prompt execution, and candidate routing.
* **Architecture**:
  * Modular backend built with **Python** and **FastAPI**, structured into distinct orchestrator, synthesis, and evaluation services.

`Python` · `FastAPI` · `AI Orchestration` · `Context Isolation` · `LLM Pipeline`

<br>

### 🩺 [DermaSense](https://github.com/bitsbynilesh/DermaSense)

A cross-platform mobile skin-health tracking application designed for proactive dermatological monitoring and structured symptom documentation.

* **Implemented Application Features**:
  * Cross-platform mobile client built using **React Native** and **Expo**.
  * Multi-screen application architecture featuring guided user onboarding, interactive dashboard, and skin diary logs.

  * Client-side state management for historical skin symptom tracking.
* **Planned AI-Model Integration**:

`React Native` · `Expo` · `JavaScript` · `Mobile UI/UX` · `AI Integration Roadmap`
